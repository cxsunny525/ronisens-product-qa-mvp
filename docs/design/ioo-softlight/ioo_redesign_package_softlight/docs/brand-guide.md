# IOO mini brand guide — Soft Light Lab

## Brand position
Industrial Optics Online is a bright, calm, engineering-first workspace for machine vision lighting selection.

## Visual direction
- Use a light, low-glare laboratory feeling instead of a dark cockpit.
- The page should feel like visual rest after code, CAD drawings, inspection images, and noisy production environments.
- Mist white, pale blue-green, and soft graphite create technical trust without heaviness.
- Teal is used for optical focus and answer confidence.
- Amber is used only for credit/reward moments and key completion feedback.
- Green is reserved for verified, approved, or ready-to-quote states.
- Avoid pure black backgrounds, large dark blocks, intense red alerts, and noisy gradients.

## Typography
- UI: Inter, IBM Plex Sans, system UI fallback
- Technical values: JetBrains Mono, SFMono-Regular, Consolas fallback

## Logo concept
The IOO mark combines an optical target, coaxial inspection axis, and illumination beam. In the Soft Light Lab theme, the logo sits on a mist-white tile rather than a dark block.

## Accessibility notes
- Minimum text contrast should target WCAG AA.
- Touch targets should be at least 44px on mobile.
- Avoid thin low-contrast text on pale backgrounds.
- Use amber sparingly so credits remain salient.
