# IOO UI redesign rationale — Soft Light Lab revision

## Core product idea
IOO should feel like a quiet engineering workspace: bright, low-glare, precise, and always helpful. The page should make the engineer want to stay, ask another question, save another useful answer, and build credits toward real benefits.

## Why this revision removes the dark theme
The first version used a dark engineering-cockpit metaphor. The revised version avoids a large black or charcoal base because it can feel heavy and enclosed. Engineers already spend long hours facing code, CAD, inspection monitors, drawings, and production-site equipment. A soft light interface gives the eye a calmer resting field while retaining technical credibility.

## Psychological principles used

1. Cognitive load reduction
- Keep the conversation in the center.
- Move account, history, shortcuts, and product recommendations to stable peripheral zones.
- Use short labels, progressive disclosure, and persistent context.

2. Recognition over recall
- Prompt chips remind engineers what they can ask.
- Product cards show model, image, key specs, and links without forcing the engineer to search again.
- Conversation history is visible and resumable.

3. Reward loop
- Credits are visible in the top bar at all times.
- Each useful engineering action can earn small points: ask a structured question, save a case, compare products, upload an image, or request a quote.
- Rewards should be practical: sample shipping, application review, priority response, technical call, discount, or accessory kit.

4. Calm attention
- Avoid pure black and large dark panels.
- Use mist white, pale blue-green, soft graphite text, teal focus accents, and warm amber reward accents.
- Keep animation subtle and avoid flashing elements.

5. Field usability
- Mobile uses large touch targets and a bottom product drawer.
- Engineers in production environments can keep the conversation visible and open the product list only when needed.
- Essential product actions stay one tap away: details, datasheet, quote, compare.

## Desktop layout

Left rail:
- Account status
- Credit snapshot
- Conversation history
- Field shortcuts

Center:
- Calm hero intro
- Prompt chips
- Chat messages
- Composer with attachment support
- Credit earning cue

Right rail:
- Recommended product cards
- Product image
- IOO public model number
- Key specs
- Detail/datasheet/3D/quote links
- Reward progress card

## Mobile and tablet layout

Top:
- Brand
- Credits
- Apply/sign-in entry

Middle:
- Compact account card
- Horizontal history cards
- Main chat

Bottom:
- Fixed recommended-product tab
- Opens product bottom sheet
- Keeps chat uninterrupted

## Reward system proposal

Suggested credit events:
- +5: ask a structured question with defect and surface
- +10: save an answer to case history
- +15: add product to shortlist
- +20: upload inspection image or drawing
- +25: complete application parameters
- +40: submit quote-ready request
- +60: post-project feedback or result image

Suggested benefits:
- 500 credits: priority datasheet support
- 1,000 credits: sample shipping subsidy
- 1,850 credits: application review
- 3,000 credits: engineering call
- 5,000 credits: demo kit discount or partner perk

## Naming recommendation

Use wording that sounds practical rather than playful:
- Credits, not coins.
- Engineer streak, not game streak.
- Reward progress, not game level.
- Application review, sample support, and priority quote instead of vague gifts.
